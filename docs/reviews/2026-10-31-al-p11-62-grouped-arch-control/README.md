# Artist control for grouped round-headed windows

The grouped-family workspace offers an opt-in **Group round-headed windows (demo)** choice. It creates the versioned family policy that groups windows on both flat- and round-headed family members. The workspace displays the saved choice on reopening and restores the artist's prior setting on return to the original building. When the option is off, earlier policies remain in use.

The app workflow combines the choice with uncovered entrance positions, storefront pane variation and demo awning fabrics. It checks grouped arches in the saved members, stable entrance and fabric choices across a grouped-window placement change, archive reopening and source retention. The control reports that some seeds and three-window groups require more pier clearance; failures are not silently adjusted. This is a demo awaiting visual review, not historical evidence, and the broader family remains too repetitive for a finished street.

Reproduce with `node docs/reviews/2026-10-31-al-p11-62-grouped-arch-control/verify.mjs webgl <new-output-dir>` or `webgpu`.
