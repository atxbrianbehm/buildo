# AL.P11.20 — retained sign generation study

An isolated generation adapter retains an authored sign and, when present, its awning, rods, piers and explicit shared gap across deterministic generation and rerolls. It compiles the result and rejects a missing or invalid retained storefront. The adapter requires the existing preserve-authored choice and rejects imported sign, awning and pier locks until their semantics are supported. The ordinary workspace generation path remains guarded.

Tests cover repeatability, reroll seed changes, retained directives and geometry, missing-bay rejection, the imported-lock guard and unknown architecture coverage. The WebGL textured compiler fixture renders one rerolled building with the retained storefront; it remains visually similar to the source and is not a demonstration of family or street diversity. It does not establish historical evidence. Workspace, project-lineage integration and family generation are pending.

All five documented checks passed: typecheck, lint, build, browser smoke and the full suite (2,110 tests in 176 files). The build retains its existing chunk-size warning.
