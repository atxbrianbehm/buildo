# Grouped windows and facade piers: portable study

The experimental grouped-rhythm family policy now has a version that carries the deterministic facade-pier variation plan. The archive replays that plan with the signed source, material and fabric, and verifies the final family against its receipt. Existing policy versions retain their prior behavior. This is not yet an artist-facing choice.

`family.png` and `pier-detail.png` are generated from actual textured geometry in the local WebGL study. The close view combines paired upper windows and projected piers on one signed building. These are demo choices with unknown historical coverage, not a claim about any particular place or a finished street. The storefronts and brick remain repetitive, the pier-to-horizontal-trim junctions need refinement, and this view does not constitute complete texture or silhouette review. Backlot's first cartridge and output remain undecided.

The archive test exercises combined geometry, source and material retention, replay, policy tampering, mismatched seeds, and older archive versions. Run `node docs/reviews/2026-10-31-al-p11-40-grouped-pier-replay/render.mjs` to reproduce the screenshots.

Validation: typecheck, lint, production build, full test suite (2,129 tests in 181 files), and browser smoke passed. The build retains its existing chunk-size warning. The study render uses WebGL; the browser smoke is regression coverage, not a separate visual review of this new policy in both renderers.
