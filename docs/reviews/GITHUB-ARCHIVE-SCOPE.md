# GitHub review archive scope

This repository contains the current application, tests, maintained plans, review narratives, small verification/decision records, test-required historical fixtures, and the current C6/grouped-inspector review images and source snapshots.

The full local review archive is not a GitHub backup. Large portable material/project JSON files, intermediate geometry/pixel dumps, repeated source snapshots and older capture sets remain local. No local evidence is deleted or rewritten. Original packet inventories describe the complete local packets; some attachment links in historical reports require those omitted files and are not complete-checkout verification claims.

The October24 synchronization selects a bounded archive subset so a clean checkout can build and run every repository check without committing gigabytes of generated proof data. The publication candidate is checked independently of the omitted local files. The private phone-review gallery remains at https://app.notion.com/p/3fdb77d6cd4f812a9f88f1316beb9c25.

Workflow acceptance, C6 visual acceptance, live UTDG architecture coverage and family/block readiness remain separate pending gates. Publishing the current engineering snapshot does not clear them.
