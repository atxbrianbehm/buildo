The sill uses metre-based UVs. Side/rear and ground openings remain rectangular. No renderer, material generation, provider, project codec or user-facing controls change in this packet.

The focused compiler and worker run passed 60 tests across six files; typecheck and full lint passed. The tests verify wall coverage at an arch shoulder versus the empty aperture, shared spring/contour geometry, finite normals and UV buffers, closed frame and pane edge topology, local opening-width retention, worker client request/reply, explicit invalid fit and unsupported casement rejection, and literal rectangular mesh/prototype/instance parity when the new choice is disabled. The earlier sandboxed planning test failure was a temporary-file permission error; final tests used the working outside-sandbox Vitest environment.

This is an engineering seam, not a rendered or artist-approved result. The current round-headed assembly is a simple framed pane and sill, not a double-hung sash; non-default casement layouts fail with a diagnostic rather than silently changing their assembly.
