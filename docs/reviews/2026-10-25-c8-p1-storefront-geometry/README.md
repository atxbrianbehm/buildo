The original constructors remain literal. A disabled/bypassed operator reproduces explicit C7 geometry exactly. Unmigrated graph0.4 retains its complete golden compiler hash. C7 window layouts remain explicit and unchanged.

The planner operates only on front-ground building scopes with one existing entrance. It widens display apertures while retaining piers, bulkhead and head band. The existing entrance width remains authoritative; the frontage head/transom defines the glazed door height. Existing window and door operators emit the new assemblies at the same semantic paths and material slots, so a separate overlapping geometry branch is not added. Wall and assembly layout mismatches reject.

Display frames and transom rails are chamfered timber sweeps, with two separate glass panes per bay. The glazed door has its own stiles/rails, lower recessed kick panel and beading, separate leaf and transom glazing, handle/mounts and a threshold. Metre UVs, outward winding, finite triangles and physical fit are checked. Frames/door are closed fixed-pose geometry. No preassembled meshes or image-derived structure are used.
