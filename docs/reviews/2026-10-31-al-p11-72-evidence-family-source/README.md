# AL.P11.72: Evidence source in a rhythm-family archive

This experimental versioned wrapper retains one validated opening-head application beside an existing grouped-rhythm family archive, with or without its fabric-assignment wrapper. It replays the family, checks that the application result and declared generation source exactly match the family source project, and computes each member's opening-head setting as matching, differing from, or unavailable relative to the source choice. Reopening recomputes the relations rather than trusting saved labels.

The relation compares one generated parameter; it does not establish that a member inherited the choice by causation, that the shape is historically correct, or that the source claim applies to neighboring buildings. The source claim remains unreviewed. This is not yet an artist-facing family file, and regular family archive readers do not open the wrapper. Family UI, other family formats, and more architectural evidence mappings remain separate work.

The synthetic test creates a six-member signed, awning-bearing family with actual material and fabric sources; the result contains members both matching and differing from the source opening setting. It verifies both archive variants, replay, rehashed relation tampering, and rejection of a valid application from another graph. Validation passed: typecheck, lint, production build, focused family replay, full suite with two workers (2,156 tests in 191 files), and standard browser smoke. Two workers were used because an existing family-edit test had timed out under default concurrency in earlier runs. The build retains its existing chunk-size warning.
