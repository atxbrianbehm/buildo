# AL.P11.1 — real-scope signboard compiler study

An experimental complete-building compiler request places one blank sign on an executed front storefront bay. Its material slots use existing ornament and trim sources. The compiler derives an awning conflict from the actual graph, checks its generated bounds against storey trim, rejects missing or disconnected scopes, and preserves the original building geometry and semantic identities. An awning in a different bay and existing upper piers remain supported.

The textured fixture images use the actual compiler output and renderer adapter with piers, grouped upper windows and neighboring awnings. The available head band makes the safely fitted demo sign shallow. It has no lettering and is not an artist-facing control or a saved graph directive. A shared design for signs and awnings in the same bay, material choices, evidence mapping, and visual refinement remain open; no historical coverage is claimed.

All five checks passed: typecheck, lint, build, browser smoke and the full suite (2,092 tests in 170 files). The build retains its existing chunk-size warning.
