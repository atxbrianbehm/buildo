# R6.P1 — compiled authored families

The resolver derives six deterministic member seeds from the admitted family plan, retains the authored graph choices and pinned material/reference lineage, and compiles each member with the construction compiler. It checks both graph shape and compiled geometry for diversity, trying a bounded number of deterministic candidates. If locks prevent diversity, or an authored local surface target is missing, it fails without returning a partial family or replacing the source. It snapshots inputs before asynchronous work and supports cancellation.

Ten focused tests across the family plan and generation suites pass, along with typecheck and lint. They cover deterministic replay, distinct semantic identities and geometry, retained cornice/parapet/window/storefront/opening and local finish choices, input ownership, invalid/tampered requests, cancellation, missing local targets and insufficient diversity under locks.

An additional local integration check read and validated the accepted `test-results/c10-p2-2026-10-29/webgpu-04/raised-v10.json` project, generated six distinct members, and created six valid construction projects using the exact original saved material source and each member's generation lineage. That saved project is a local review artifact, not a committed fixture. The check confirms source and material admission, not shared GPU resources or rendered quality.

P2 must still establish the actual workbench preview, resource sharing and disposal, both native renderer captures, reopen and performance evidence. Surface target existence is checked here; full material binding and renderer compatibility remain P2 checks. Historical UTDG architecture coverage and block generation remain unproven.
