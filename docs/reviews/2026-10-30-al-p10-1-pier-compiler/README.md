# AL.P10.1 — real-scope pier compiler study

An explicitly experimental, versioned compiler request adds the pier study to one complete construction graph. The compiler derives upper-floor opening spans from its actual wall scopes, including expanded grouped openings, reserves the horizontal band and cornice heights, and emits one semantically addressed `facade-pier` mesh per floor and bay edge. It rejects partial upper wall scope, ambiguous operators and insufficient clearance. The regular graph and project formats are unchanged; normal evaluation remains identical.

Focused tests compare all pre-existing wall, window and roof mesh and instance buffers with ordinary evaluation, verify ten unique addressed projecting piers, replay, grouped and round-head opening compatibility, clearance rejection and partial-wall rejection. The clay studies use the actual whole-building compiler. The textured fixture uses the existing scene adapter and material source with grouped windows, storefront glazing and striped awnings; at this captured scale there is no obvious sill or pier artifact, but detailed UV, finish targeting and actual editor/backend behavior remain unverified.

This is not yet a graph directive, worker protocol, saved project, artist control or family variation. The pier treatment is a demo and remains visually simple; no historical evidence is asserted. All five checks passed: 2,077 unit tests across 166 files, browser smoke, typecheck, lint and build. The focused clearance test and final textured fixture were rerun after the scope guard correction. The build retains its existing chunk-size warning.
