# AL.P9.2b: Awning generation retention

Single-building generation retains authored awning bay directives when edited assemblies or opening locks are kept, and explicitly releases them when both are released. It checks retained geometry against the generated storefront and reports infeasible or missing bays. The workspace retains the independent fabric even when the atlas library is replaced, and keeps the fabric available after an explicit awning release. Family preview remains guarded pending family-source and shared-resource integration.

Focused tests cover retained and released directives, opening-lock retention and a target that cannot fit a reduced bay count. Actual [WebGL](webgl-rerolled.png) and [WebGPU](webgpu-rerolled.png) editor captures show a retained demo awning after reroll; both workflows check the same fabric and atlas, zero new material-provider calls, undo/redo, automatic recovery and explicit project reopen. A separate WebGL material-seed change replaced the atlas and retained the awning and fabric. Full repository validation is pending. The canopy is still rigid, and its dimensions and fabric are demo choices. The verification script uses the locally retained P6.2 project at `docs/reviews/2026-10-30-al-p6-2-storefront-authoring/webgpu-02/divided.json`.
