# AL.P9.2m: Support retention during building generation

A single-building reroll preserves authored support rods alongside awnings when edited assemblies or opening locks are retained, and releases both when those protections are explicitly disabled. Generated geometry is evaluated before publication; infeasible retained supports fail without replacing the last valid building. Family generation rejects support-bearing sources until family persistence can retain them.

Actual [WebGL](webgl-rerolled.png) and [WebGPU](webgpu-rerolled.png) workflows exercise authored rods, reroll, the family guard, undo/redo, recovery and save/reopen; the fabric and atlas remain unchanged and no additional material-provider calls occur. The script uses the locally retained P6.2 project at `docs/reviews/2026-10-30-al-p6-2-storefront-authoring/webgpu-02/divided.json`. Rods remain illustrative and lack attachment plates. All five repository checks passed: 2,067 tests across 161 files, standard browser smoke, typecheck, lint and build. The build retains its large-chunk warning.
