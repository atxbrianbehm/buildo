# C10.P2 phone review

The [phone gallery](https://app.notion.com/p/3fdb77d6cd4f812a9f88f1316beb9c25) contains six actual WebGPU workbench images from [PR #25](https://github.com/atxbrianbehm/buildo/pull/25): flat and raised whole views, the raised textured and map-disabled close-ups, and similar raised and flat rear views showing unresolved ground-shadow gaps. The rear cameras differ; the comparison does not establish the cause of those gaps.

On October 29, the six immutable URLs returned PNG bytes identical to the archived local captures. Gallery readback contained 164 image references, preserving all 158 previous references and adding the six intended images. Visual review is pending.
