# AL.P5.3: grouped windows in the construction workspace

The [grouped-window controls](webgpu-reviewed/grouped-controls.png) let an artist select a front upper storey and bay, choose a single, paired or triple opening, and adjust member and pier widths. Apply uses the existing atomic publication and history path. Invalid fit, a local parent-bay width override, or a rounded head returns a reason and retains the last valid building. Removing the last group returns the graph to the preceding format. Grouped member frames do not masquerade as the existing single-window width target. Reroll and family generation remain blocked for grouped graphs until the next packet can preserve them.

Both [WebGPU](webgpu-reviewed/receipt.json) and [WebGL](webgl-reviewed/receipt.json) exercised pair and triple changes in the actual workspace, saved each, undid back through both edits, redid the pair, explicitly reopened it in a fresh page, and confirmed the same material source and zero additional material-provider calls during those structural edits. The triple was saved and exercised through undo; a fresh-page reopen of the triple was not tested. [Workflow](verify.mjs) requires the locally retained C10 source file. [WebGPU paired textured view](webgpu-reviewed/grouped-close.png), [triple textured view](webgpu-reviewed/triple-close.png), [clay view](webgpu-reviewed/grouped-clay.png), and [WebGL triple view](webgl-reviewed/triple-close.png) are actual app captures.

The separate openings and masonry read in the close views, although the small trim gaps are subtle and a fine reddish sill line remains visible. These static captures do not establish a fix for the prior sill line, all texture interactions, historical correctness, or street readiness. The initial captures before the final conflict-message change are excluded from this packet's final evidence. User visual approval has not been inferred.

Verification at initial review: focused workbench test, typecheck, lint, build, standard E2E and both renderer workflows passed; the full suite was running. One lint attempt included capture-generated Vite caches; those owned caches were removed and the clean lint passed. The build retains its large-chunk warning.
