# AL.P9.2t: Individual family fabric authoring

Artists can assign a solid or striped fabric and colors to a selected family building, or return that building to the inherited fabric. A new family source retains explicit assignments independently of the shared fabric and structural graphs. Applying changes rebuilds the family view atomically; unsaved family changes are disclosed, and construction undo does not undo fabric changes.

Actual [WebGL](webgl-family.png) and [WebGPU](webgpu-family.png) app workflows create red and blue overrides, retain inherited fabric on other buildings, reset one override, save and reopen, and verify graph and atlas sources stay unchanged with no additional material-provider calls. A WebGL check reorders saved assignments and verifies controls follow building identity. The script uses the locally retained P6.2 project at `docs/reviews/2026-10-30-al-p6-2-storefront-authoring/webgpu-02/divided.json`. These colors are illustrative; broader facade variety and historical evidence remain pending. All five repository checks passed: 2,069 tests across 163 files, standard browser smoke, typecheck, lint and build. The build retains its large-chunk warning.
