# Metagrinder extract staging boundary

This isolated boundary stages a narrow projection of the public Metagrinder extract contract inspected at commit `8485396ad0deaf99cca0d3794825f536ec748a26`: [runtime schema](https://github.com/WildConstruct/metagrinder/blob/8485396ad0deaf99cca0d3794825f536ec748a26/packages/core/types/metagrinder.runtime.js) and [extractor](https://github.com/WildConstruct/metagrinder/blob/8485396ad0deaf99cca0d3794825f536ec748a26/packages/core/services/researchExtract/index.js). The caller declares that producer revision; the declaration is not independently authenticated. This does not claim compatibility with later or different producers.

The versioned, hash-checked envelope retains the complete input JSON, including unrelated and unknown fields. It indexes claims explicitly categorized `architecture-and-streetscape`, retaining their text, IDs, all source-input and source-chunk IDs, categorical confidence and attribution mode. The index always labels them unreviewed and architecture coverage unknown. It does not infer typed architectural choices, establish source authenticity or rights, convert categorical confidence to a number, promote a claim, or modify the existing generation snapshot. Nonempty identifiers and unique claim IDs are additional admission requirements; other parts of the upstream artifact are retained as opaque JSON rather than fully validated against the upstream schema.

The tests use synthetic content only. They cover ownership, preservation, multiple source IDs, unknown fields, missing claims, duplicate IDs, malformed input, revision mismatch, promotion and rehashed-index tampering. This is not a live Metagrinder connection, an evidence review workflow, a UTDG architecture dataset or a building-generation integration. Further packets must connect an explicit human-reviewed mapping and preserved provenance to actual authoring before claiming a functional evidence-driven building workflow.

Validation passed: typecheck, lint, production build, focused staging tests and the full suite (2,145 tests in 185 files). The first browser smoke timed out within the existing surface-continuity workflow while running alongside the suite; the complete solo rerun passed. The build retains its existing chunk-size warning.
