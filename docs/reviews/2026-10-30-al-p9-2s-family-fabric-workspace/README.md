# AL.P9.2s: Individual-fabric family workspace

The family workspace opens a validated per-member fabric source, renders its assigned fabrics, gives a selected member its own material during structural editing, and preserves assignments through return, save and reopen. Different fabrics retain independent resources; identical sources share them. Member fabric controls remain disabled, so the example assignment is supplied by the test file rather than created through the UI.

Actual [WebGL](webgl-family.png) and [WebGPU](webgpu-family.png) family previews show one red override among inherited green-striped awnings; the [member view](webgl-member.png) shows its assigned fabric. Both workflows verify structural member edits, unchanged siblings and assignments, save/reopen and zero additional material-provider calls. The script uses the locally retained P6.2 project at `docs/reviews/2026-10-30-al-p6-2-storefront-authoring/webgpu-02/divided.json`. This does not establish street readiness or historical color evidence. All five repository checks passed: 2,068 tests across 162 files, standard browser smoke, typecheck, lint and build. The build retains its large-chunk warning.
