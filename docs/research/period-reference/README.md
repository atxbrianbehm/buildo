# Period reference image pack (HABS / LOC)

Curated public-domain facade references for manual visual QA against Buildo kit-mode output.

## Contents

| File | Use |
|---|---|
| `images/01-…`–`07-…` | Downloaded HABS / Detroit Publishing images |
| `images/SOURCES.json` | Source URLs, titles, rights |
| `../ref/catalog.json` | Unified catalog including these entries (`collection: "habs"`) |

## Rights

U.S. government HABS/HAER works and many Detroit Publishing items are public domain. Keep LOC item links when redistributing.

## App surface

Period Ref Lab (`#room=periodRef`) serves these under `/period-ref/habs/…` during `npm run dev`.

Primary HABS targets for single-building clay compare:

- Columbus OH brick commercial & apartment front
- Jefferson City MO brick commercial facade
- Cornice + window-hood detail shots (trim layering)

See `docs/ref/README.md` for the full compare protocol.
